## 三、常用答疑备用话术

在评论区互动时，可直接使用以下话术快速回复潜在用户：

| 提问场景 | 回复话术参考 |
| :--- | :--- |
| **会被官方封号吗？** | 绝对不会！市面外挂被封是因为模拟点击、代收代偷或内存注入。这个 App 完全不点屏幕、不拦截网络，本质上就是一个能“自动看倒计时的闹钟”，不破坏任何游戏平衡。 |
| **截图会泄露我的隐私吗？** | 绝无上传。软件内置的是 Google ML Kit 离线文字识别引擎，甚至在系统层没有声明网络权限（INTERNET），飞行模式下也能用，所有数据只存放在手机本地私有沙盒。 |
| **为什么没自动弹出提醒？** | ① 请确认点击作物调出了完整的倒计时弹窗（如“xx:xx:xx后成熟”）；② 国产定制系统（小米/华为/OPPO/vivo 等）请在系统设置中将应用的电池优化设为“无限制/允许后台高耗电”并允许自启动。 |
| **支持 iOS（苹果手机）吗？** | 目前仅支持 Android 11 及以上系统（因为依赖系统原生的无障碍静默单帧截屏 API），iOS 系统底层权限受限暂无法实现。 |
